## 🚀 To Get Gmail Emails (5 Minutes)

### 1. Get Your Gmail App Password
```
→ Go to: https://myaccount.google.com/apppasswords
→ Make sure 2-Factor Auth is enabled
→ Select: Mail + Your Device
→ Copy the 16-character password
   (Example: abcd efgh ijkl mnop)
```

### 2. Update .env File
```bash
nano /home/asenic/homelab-ai-code/.env
```

**Change these lines:**
```
GMAIL_EMAIL=your-actual-email@gmail.com
GMAIL_APP_PASSWORD=abcdefghijklmnop
```

**Save:** `Ctrl+O` → `Enter` → `Ctrl+X`

### 3. Restart Backend
```bash
cd /home/asenic/homelab-ai-code
docker compose -f docker-compose.yml restart backend
```

**Wait for:** `🚀 Server running at http://localhost:5000`

### 4. Test Registration
```
→ Go to: http://localhost:3000/register
→ Register with your Gmail address
→ Check Gmail inbox for verification email
→ Click verification link
→ You're done! ✅
```

## 📋 Configuration Reference

### Docker Compose Variables
```yaml
EMAIL_SERVICE: smtp                    # Use SMTP (not Ethereal test)
SMTP_HOST: smtp.gmail.com             # Gmail SMTP server
SMTP_PORT: 587                        # TLS port
SMTP_USER: your-email@gmail.com       # Your Gmail address
SMTP_PASS: abcdefghijklmnop          # App password (no spaces!)
EMAIL_FROM: your-email@gmail.com      # Email sender address
BASE_URL: http://localhost:3000       # Your app URL
```

### Env File Variables
```
GMAIL_EMAIL=your-email@gmail.com
GMAIL_APP_PASSWORD=your-app-password
```

## ⚠️ Important Security Notes

### App Password Security
- ✅ 16-character password generated by Google
- ✅ Only works with 2-Factor Authentication
- ✅ Can be revoked anytime from apppasswords page
- ⚠️ Keep this password secure (treat like regular password)
- ⚠️ Don't share in emails, commit to git, etc.

### Best Practices
1. **Don't commit .env to Git** - Add to .gitignore
2. **Keep app password safe** - Only in .env file
3. **Review Gmail security regularly** - Check apppasswords page
4. **Use different app passwords** - One per app/service
5. **Generate new password if leaked** - Simple to revoke
